The problem

Every team pays someone to do the busywork.

The daily scrum-master grind
  • Chase everyone: "what did you do yesterday?"
  • Move tickets when the code actually merges
  • Write each person's standup, by hand
  • Notice what's stuck before it's too late
  • Run the meeting even when there's nothing to say
~30 min
per engineer, every day — on coordination no one wants to do, and everyone forgets to.
